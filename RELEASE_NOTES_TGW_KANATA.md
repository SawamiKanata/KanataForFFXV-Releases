# KanataForFFXV 1.0 — Official Release

The first official KanataForFFXV release for Windows x64.

- Browse local game resources and use the supported editing, preview, project, and Mod workflows described in the user guide.
- English and Japanese interfaces, with a bundled runtime.
- Prepare and install enabled Mods before launching the game, with restoration after exit.
- Kanata theme colors and top-center branding accompany Mods built with the public edition.
- Retains package integrity checks and online regional availability verification.

This release promotes the tested program to version 1.0 and includes the supplied English/Japanese statement. The application binaries are unchanged from the verified build.

HUD/UI editing remains unstable; preview is recommended. Resource loading and Mod building may take time. Supported formats and limitations are documented in the [statement and guide](https://github.com/SawamiKanata/KanataForFFXV-Releases/blob/main/docs_TGW_KANATA/software_statement_en-US_ja-JP_TGW_KANATA.md).
