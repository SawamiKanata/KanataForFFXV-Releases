# KanataForFFXV 1.0

Official binary release and documentation for **KanataForFFXV**, a Windows desktop resource and Mod editor for FINAL FANTASY XV.

## Download

[Download KanataForFFXV 1.0 Setup (Windows x64)](https://github.com/SawamiKanata/KanataForFFXV-Releases/releases/download/v1.0/KanataForFFXV_1.0_Setup_x64.exe)

The installer includes its runtime and the English/Japanese software statement. No separate Python installation or compilation tools are required. The installer supports English and Japanese; the editor defaults to Japanese and can be changed to English in Preferences.

Verify the download using [SHA-256 checksums](SHA256SUMS_TGW_KANATA.txt).

## Getting started

1. Run the installer and choose an installation folder.
2. Start KanataForFFXV and select your own game installation. Original game resources are required for supported editing and building. Platinum Demo is an optional separate resource source.
3. Save editable projects as `.kanataproject`; build and import `.kanata` packages through Mod Manager.
4. Launch the game through Kanata to use enabled Mods. Corresponding game files are prepared before launch, remain fixed during play, and are restored after the game exits.

An internet connection and regional availability verification are required during use. Follow the application's verification results and messages. Save projects regularly.

Mods built with Kanata include Kanata theme colors and branding. Their retention requirements and all usage limitations are described in the statement below.
